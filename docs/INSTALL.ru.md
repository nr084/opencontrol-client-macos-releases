# Установка и удаление

**Рабочий PKG пока не опубликован.** Ниже описан процесс для будущего подписанного
выпуска. Не требуется отключать SIP, Gatekeeper или проверку сертификатов.

## Будущий подписанный выпуск

1. Скачайте Universal PKG со страницы Releases, проверьте SHA256.
2. Установите в `/Applications`; файл называется `OpenControl Client.app`.
3. При первом подключении разрешите сетевое System Extension в системных настройках
   и создание VPN-конфигурации. Расположение раздела разрешений зависит от macOS.
4. Добавьте адрес, порт (по умолчанию 4090), логин и пароль от администратора.
5. Для собственного сертификата просмотрите его, сверьте SHA-256 с администратором
   и подтвердите доверие. Альтернатива — доверенный CA-сертификат PEM.
6. Подтвердите уведомление о VPN и подключитесь.

Русский/английский язык, профиль по умолчанию для строки меню и исключения сетей
настраиваются в «Настройках». Изменения профиля/маршрутов применяются при следующем
подключении. Для импорта Android-профиля выберите изображение QR либо JSON-файл.
QR содержит пароль; не публикуйте его.

## Удаление

1. В приложении откройте «Настройки → Подготовить удаление».
2. Если нужно, отдельно включите удаление профилей и паролей из Связки ключей.
3. Подтвердите удаление VPN-конфигурации и деактивацию System Extension.
4. Если macOS требует перезагрузку, перезагрузитесь до завершения удаления.
5. Завершите приложение и запустите `Uninstall OpenControl Client.command` из
   комплекта выпуска. Сценарий также доступен внутри пакета приложения в
   `Contents/Resources/Uninstall.command`.
6. Подтвердите удаление; пароль администратора вводится только в локальном Терминале.

Сценарий проверяет идентификатор приложения, удаляет только OpenControl Client.app
и его квитанцию PKG. Другие VPN и системная база SystemExtensions не затрагиваются.
Профили и пароли по умолчанию сохраняются, пока не выбран отдельный пункт очистки.
