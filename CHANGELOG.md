# История / Changelog

## 0.1.0 — в разработке / in development

Публичного бинарного выпуска пока нет. Подпись Apple Developer и испытания VPN
на реальном сервере остаются обязательными шагами. По решению владельца версия
только для просмотра интерфейса не распространяется.

Implemented: Universal 2 SwiftUI app, RU/EN, Android icon/profile/QR compatibility,
Keychain, explicit certificate trust, Rust protocol engine, System Extension,
network exclusions, reconnect, statistics, menu bar and PKG/removal scripts.

OpenControl Protocol 0.2.0, Rust 1.99.0. No public binary release yet; Apple signing
and real-server acceptance remain pending. A UI-only test version is not distributed.
