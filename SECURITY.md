# Security / Безопасность

Do not include credentials, private keys, corporate server addresses or traffic
captures in public issues. Report reproducible problems using synthetic data.

Не публикуйте учётные данные, закрытые ключи, адреса корпоративных серверов и
записи трафика. Для воспроизведения используйте синтетические данные.

No public VPN server or corporate test account is provided by this project.
The current macOS implementation is not yet accepted for production use.
